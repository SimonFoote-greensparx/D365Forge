| D22 | How the profile builder writes profiles | Patch the string-built YAML; build a profile object, check it, then serialise it | The builder assembled YAML by joining strings, which nested each integration inside a second list and silently dropped integration details it did not recognise. Integrations, systems to retire, channels, data sources, licences, compliance, change freezes, names and output formats now have their own fields. The logic lives in `docs/assets/profile-builder.js`, and `scripts/check-profile-builder.py` runs it in Node.js and validates its output on every build. | 2026-10-16 |
