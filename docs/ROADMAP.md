# Roadmap

The plan runs for about 24 weeks of part-time effort by two people. Robert Peledie specifies each department roughly a
phase ahead of the build and reviews and tests it afterwards. Re-baseline at the end of Phase 1 once the real pace is known.

## Where we are

**First draft published (October 2026).** Every department, skill, template, data file and the website exist as a
first draft. Every skill is `status: draft`. The next step is review, starting with Customer Service.

## Phases

| Phase | Weeks | Objective | Exit criteria |
|---|---|---|---|
| 0. Foundations | 1-2 | Agree scope, conventions and roles | Decisions D1-D16 recorded; repository protected with Rob as required reviewer |
| 1. Walking skeleton | 3-4 | Prove build and install in both runtimes with `customer-service` | Skills install and trigger in Claude Code and ChatGPT or Codex; Rob's first review passed |
| 2. Sales and Customer Service | 5-9 | Review and harden the two most common modules and the core delivery disciplines | About 35 skills at `status: reviewed` |
| 3. Marketing and Field Service | 8-12 | Review the remaining modules and their data and integration touchpoints | About 60 skills reviewed; hand-off scenarios pass Rob's tests |
| 4. Reviewers, sources and editions | 11-15 | Governance, cited authorities and scale awareness | All skills reviewed; SMB and Enterprise fragments written; both editions verify |
| 5. Tailoring engine | 14-18 | Turn a profile into a tailored pack | Rob validates the SMB and enterprise sample packs against real practice |
| 6. Website and beta | 17-21 | Make it usable by strangers | Public website; closed beta with 5-10 CRM practitioners; feedback triaged |
| 7. Launch | 22-24 | Release v1.0 and open to contributors | Tagged release, launch article, first external pull request reviewed |

## After v1.0

- Industry packs emitted like editions (for example utilities field service, public sector case management).
- Finance and operations and Business Central touchpoints beyond the CRM side.
- A review sprint after each major Microsoft release, tracked against the AI at Work roadmap.
