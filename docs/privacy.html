Privacy

D365Forge is a library of skills, templates and documentation. It does not run a service, and it does not collect, store or send any personal or organisation data.

This website

The website is a set of static pages hosted on GitHub Pages. It sets no cookies of its own and has no analytics. GitHub, as the host, may log requests as described in GitHub's own privacy statement.

The profile builder

The profile builder runs entirely in your browser. Nothing you type is sent anywhere; the profile file is created on your device when you select Download.

The skills and plugins

The skills are instructions that run inside the AI assistant you install them in, such as Claude Code, ChatGPT, Codex or Microsoft Copilot Cowork. Any data you share in those conversations is processed under that product's terms and your organisation's agreement with its provider, not by this project. The tailoring skills write organisation profiles and generated documents only to your own storage, never to this repository.
